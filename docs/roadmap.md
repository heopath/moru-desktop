# 모루 추가 요구사항

기록일: 2026-10-18 (Asia/Seoul)

이 문서는 사용자가 추가한 방향과 구현 후보를 기록한다. 완료 표시가 없는 확장 기능은 아직 구현되지 않았다.
v0.3.0은 PNG와 기본 스킨 애니메이션, Codex 로컬 기록 관찰, Claude Code 훅·상태줄 연결을 지원한다. 현재 연결 방법과 제약은 [README](../README.md#ai-도구-연결)를 기준으로 한다. 아래 공식 App Server 조사는 향후 안정적인 연동을 위한 후보 검토 기록이다.

## 우선순위

0. **v0.4.0 완료:** 호버·대시보드·설정 분리, 다크 모드, 큰 글자, 날짜·시간·예약 알람, 전체/앱별 볼륨. 이후 확장도 자주 보는 정보만 대시보드에 두고 조정 항목은 설정으로 모은다.
1. **완료:** 첫 버전의 창 표시 확인·수정, 클릭·스킨 전환 검증, 실제 자원 사용량 측정. [검증 기록](verification.md)
2. **v0.7.0 완료:** PNG 선택·등록·적용·복원, 다섯 가지 상태별 이미지, AI 이미지 제작 안내. 크기 조절·이름 편집은 후속 작업.
3. **관찰용 첫 단계 완료:** Codex 사용량·메인/보조 작업, Claude Code 훅·상태줄, 짧은 상태별 움직임. 전체 작업의 완전한 동기화와 상태별 스프라이트는 후속 작업.
4. 선택한 다른 프로그램의 창 투명도 조절·숨김 기능 검토. 사용자는 당장 구현할 기능으로 확정하지 않았다.
5. **v0.7.0 완료:** 자동 실행 기본 꺼짐, 설정에서 켜기·끄기, 첫 실행에 바탕화면 바로가기 생성.

## 사용자 캐릭터

- 사용자 흐름: 친구 추가 → 이미지 선택 → 크기·바닥 위치 미리보기 → 이름 입력 → 적용.
- 최소 입력은 투명 배경 PNG 1장. JSON을 직접 작성하지 않아도 앱이 설정을 생성한다.
- 선택 입력은 작업 중·완료·주의·휴식 이미지. 없는 상태는 기본 이미지로 대체한다.
- AI에 붙여 넣을 프롬프트, 이미지 규격, 예시, 상태별 제작 순서를 제공한다.
- 외형과 PC/Codex 데이터 연동은 분리한다. 어떤 캐릭터도 같은 기능을 사용한다.
- 첫 단계는 정지 이미지 교체, 이후 선택적 짧은 애니메이션. 상시 움직임은 기본으로 요구하지 않는다.
- 자세한 제안은 [캐릭터 제작 가이드 초안](custom-character-guide.md)에 기록한다.

## Codex 패널

사용자는 Codex 사용량과 현재 메인 작업·보조 작업 상황을 함께 보고 싶어 한다.

제안하는 표시 항목:

- 사용 한도: 응답으로 제공되는 기간·사용 비율·초기화 시각. 특정 기간을 코드에 고정하지 않는다.
- 토큰: 작업별 소비량 및 제공되는 계정 사용 요약. 한도 비율과 토큰 수는 분리하고 결제 금액으로 환산하지 않는다.
- 메인 작업: 제목, 실행 중/승인 대기/완료/실패/중단, 경과 시간.
- 보조 작업: 실제 부모·자식 관계가 확인된 작업만 하위 목록으로 표시.
- 연결 끊김·오래된 정보·지원하지 않음은 별도 상태로 표시. 0%나 완료로 간주하지 않는다.
- 캐릭터 반응: 실행 중 이미지, 완료 시 짧은 반응, 사용자 조작 필요 시 작은 표시.
- 실제 진행률을 제공하지 않으면 임의의 완료 퍼센트를 만들지 않는다.

### 공식 문서에서 확인한 연동 후보

[OpenAI 공식 Codex App Server 문서](https://learn.chatgpt.com/docs/app-server)에 다음 인터페이스가 문서화되어 있다.

| 정보 | 후보 인터페이스 |
| --- | --- |
| 사용 한도 | `account/rateLimits/read`, `account/rateLimits/updated` |
| 작업 토큰 | `thread/tokenUsage/updated` |
| 계정 사용 요약 | `account/usage/read` — 인증 방식과 반환 필드에 제약이 있음 |
| 작업 상태 | `thread/status/changed`, `turn/started`, `turn/completed` |
| 작업 목록·관계 | `thread/list`의 `sourceKinds`, 실험적 `parentThreadId`/`ancestorThreadId` 필터 |

설치된 CLI는 조회 시 `0.163.0-alpha.10.2`였으며, 도움말에 app-server와 스키마 생성 기능이 있다.
App Server로 실제 계정에 접속하거나 사용량을 조회하지 않았다. v0.3.0에서는 별도 서버 실행 없이 로컬 기록에 포함된 실제 한도·토큰과 작업 이벤트 수신을 확인했다.

**문서에 인터페이스가 있다는 사실만으로, 별도 실행한 모루가 현재 Codex 데스크톱 앱의 모든 작업을 관찰할 수 있다고 확정하지 않는다.**
공유 서버·구독 범위·인증·설치 버전 호환성을 먼저 검증한다. `notLoaded`를 작업 완료로 오해하지 않는다.
모루가 연결한 세션에 대한 표시부터 검증하고 기존 데스크톱 세션 관찰은 별도 지원 범위로 다룬다.

기본 모드는 관찰용으로 설계한다. 사용량 표시만을 위해 새 AI 작업을 실행하지 않는다.
사용자가 Codex 연동을 켰을 때만 연결하고, 이벤트를 받아 바뀐 항목만 갱신하는 방식부터 검토한다.
연동용 프로세스까지 포함한 CPU·메모리를 측정한다. 본체의 가벼운 동작 목표를 유지한다.

## 선택한 프로그램의 창 투명도 — 후순위 아이디어

- 사용자가 대상 창을 직접 선택하고 투명도를 조절하거나 잠시 숨기는 기능.
- 단축키·트레이의 모두 복구, 원래 투명도 저장·복원 동작을 함께 설계한다.
- 창 재생성·프로그램 종료·권한 차이·모루 비정상 종료 시의 복구 방법을 검토한다.
- 시각적 투명도와 프로그램의 실행·자원 사용은 별개로 취급한다.
- 화면 공유·캡처에서 숨기는 기능은 다른 기능이므로 현재 요구사항에 포함하지 않는다.

- 블로그용 제작 과정과 측정 조건이 포함된 성능 결과.
