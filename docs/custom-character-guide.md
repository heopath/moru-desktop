# 사용자 캐릭터 제작 가이드

v0.2.0부터 **+ PNG 친구 추가** 버튼으로 이미지 한 장을 불러올 수 있다.
이름은 파일 이름에서 가져오며, 적용된 캐릭터는 재실행해도 복원된다. JSON을 직접 작성할 필요가 없다.
v0.8.0부터 캐릭터를 선택한 뒤 **선택한 캐릭터 관리**에서 이름 변경(1~12자)과 삭제를 할 수 있다. 삭제는 모루의 복사본만 지우며 원본 PNG는 보존한다. 기본 캐릭터는 **목록에서 제거** 후 **기본 캐릭터 복원**으로 되돌릴 수 있다. 마지막 한 명은 남긴다.
v0.7.0부터 상태마다 다른 PNG를 지정할 수 있다. 상태가 바뀌면 이미지가 교체되고, 몸 전체를 이동·회전하는 짧은 애니메이션도 적용된다. 각 상태 안에서 여러 프레임을 재생하는 스프라이트 애니메이션은 아직 지원하지 않는다.
v0.4.0에서는 캐릭터 클릭 → ⚙ → **캐릭터** 탭에서 PNG 추가, 동작 미리보기, 애니메이션 켜기·끄기, 소개 화면 저장을 함께 할 수 있다.

## 가장 간단한 준비물

**투명 배경 PNG 한 장**이면 시작할 수 있다.

| 항목 | 권장 규격 |
| --- | --- |
| 이미지 | 512 × 512 px 정사각형 PNG |
| 배경 | 실제 알파 투명 배경. 체크무늬를 그려 넣은 이미지는 투명 이미지가 아님 |
| 캐릭터 | 전신 1개, 중앙 배치, 귀·꼬리·발이 잘리지 않음 |
| 여백 | 가장자리에 약 10% |
| 방향 | 정면 또는 약간의 측면. 모든 상태에서 동일하게 유지 |
| 글자 | 이름·말풍선·글자는 이미지에 넣지 않고 앱에서 표시 |
| 화면 크기 | 약 140×134px 영역 안에 비율을 유지하여 표시. 크기 조절은 아직 없음 |
| 입력 제한 | 가로·세로 각각 최대 2048px, 파일 최대 8 MiB |

앱은 긴 변을 최대 320px로 디코딩하고 작은 복사본을 사용자 데이터 폴더에 저장한다. 원본을 수정하지 않으며 큰 원본을 매번 다시 읽지 않는다.
파일 형식·크기·가로·세로 크기를 검사하며, 원본의 알파 투명도를 유지한다. 배경을 자동으로 지우지는 않는다.
추가 후 실제 바탕화면 캐릭터와 친구 목록에서 모양을 확인한다. 숨긴 기본 스킨도 포함해 총 12개(사용자 PNG 9개)까지 보관할 수 있다. 공간이 부족하면 추가했던 친구를 삭제한다.

## AI에 넣을 기본 프롬프트

> Windows 바탕화면에 작게 표시할 [캐릭터 설명]을 만들어 줘. 정사각형 512×512 PNG, 실제 투명 배경, 캐릭터 한 명의 전신, 중앙 배치. 정면을 바라보는 편안한 대기 자세. 작은 크기에서도 알아보기 쉬운 실루엣과 선명한 눈·입. 귀·발·꼬리가 잘리지 않도록 가장자리에 약 10% 여백을 남겨 줘. 텍스트·워터마크·말풍선·배경 장면·바닥 그림자는 넣지 마. 같은 캐릭터로 여러 상태 이미지를 만들 예정이므로 형태와 색상을 명확하게 유지해 줘.

AI가 원하는 파일 크기나 실제 투명을 보장하지는 않으므로 결과를 앱에서 확인한다.
기본 이미지의 투명 배경·실루엣이 마음에 든 다음 상태 이미지를 만든다.

## 상태별 이미지 넣기

1. ⚙ → **캐릭터 → + PNG 친구 추가**에서 기본 이미지를 선택한다.
2. **상태별 모습**에서 쉬는 중·작업 중·완료·확인 대기·오류 중 하나를 선택한다.
3. **PNG 선택**으로 해당 상태의 이미지를 넣는다. 이름은 자유롭게 정해도 된다.
4. **이 모습으로 움직여 보기**를 누르면 바탕화면에서 5초 동안 확인할 수 있다.
5. **기본 이미지로**를 누르면 해당 상태만 초기화한다. 비워 둔 상태는 처음 추가한 PNG를 사용한다.

기본 벡터 스킨 3종은 상태 이미지를 편집하지 않는다. 먼저 내 PNG 친구를 추가해 선택한다.
AI 연결을 켜면 수신된 작업 상태에 따라 자동 전환되며, 연결하지 않아도 미리보기와 클릭 시 반응을 볼 수 있다.

| 파일명 제안 | 표정·자세 | 필수 여부 |
| --- | --- | --- |
| `idle.png` | 평소 대기 | 필수 1장 |
| `working.png` | 집중하거나 작업하는 모습 | 선택 |
| `done.png` | 기뻐하거나 손을 흔드는 모습 | 선택 |
| `waiting.png` | 확인·승인을 기다리는 모습 | 선택 |
| `error.png` | 놀라거나 당황하는 모습 | 선택 |

각 상태는 따로 생성하되 기본 이미지를 참조 이미지로 첨부한다. 여러 칸을 한 이미지에 넣는 방식은 첫 버전에서 요구하지 않는다.
전신 크기·발바닥 기준선·카메라 방향을 같게 유지하면 상태가 바뀔 때 캐릭터가 튀지 않는다.

추가 프롬프트:

> 첨부한 캐릭터의 외형·색상·비율·선 스타일·화면 내 크기·발바닥 위치·시점을 그대로 유지해 줘. 이번에는 [작업에 집중하는 / 완료해서 기뻐하는 / 확인을 기다리는 / 오류에 놀라는] 표정과 자세로 바꿔 줘. 원본과 같은 크기의 실제 투명 PNG로 만들고, 새 캐릭터나 배경·글자는 추가하지 마.

## 향후 편의 기능 — 현재 미지원

1. 크기·바닥 위치를 편집한다.
2. 패널 강조색, 제작자·출처·사용 조건을 편집한다.
3. 스킨 팩 내보내기·가져오기를 추가한다.

기본은 정지 이미지다. 애니메이션을 추가하더라도 표시 중인 캐릭터에만 제한된 프레임 갱신을 사용하고,
숨겨진 상태나 절전·잠금 상태에서는 멈추도록 한다. 최대 프레임 수와 메모리 제한은 실제 측정 후 정한다.

## 적용 화면 저장과 공개

**소개 화면 저장**은 현재 패널과 캐릭터를 PNG로 저장한다. 바탕화면과 다른 앱은 포함하지 않는다.
이미지에 담기는 CPU·메모리는 촬영 당시 PC 전체 수치이며, 모루 자체의 자원 사용량을 뜻하지 않는다.
공개할 사진에는 본인이 만들었거나 공개할 권한을 가진 캐릭터를 사용한다. 프로그램의 MIT 라이선스는 가져온 캐릭터 이미지에 적용되지 않는다.
